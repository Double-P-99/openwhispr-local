OpenWhispr Django Integration Prototype

Demonstrates two integration paths: (1) audio → Django proxy → whisper-server, and (2) audio → local WebSocket bridge → whisper-server.

Integration Mode

Path 1: Audio is uploaded to /api/transcribe/ (Django view), which proxies it to the local whisper-server on port 8178. Requires whisper-server running locally. All traffic goes through Django.
Path 2: Browser connects directly to the local WebSocket bridge (ws://127.0.0.1:9876). Django only serves this HTML page. Audio goes browser → bridge → whisper-server. Lower latency, fewer hops.
